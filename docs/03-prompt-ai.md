# Prompt AI yang Digunakan (lampirkan di laporan mingguan)

**Prompt 1 – Aplikasi**
> Buat aplikasi sederhana platform booking tiket konser dengan Node.js + Express dan frontend HTML ringan. Fitur: antrean (waiting room), denah kursi, hold kursi sementara dengan kedaluwarsa, pembayaran simulasi. Cegah double booking secara atomik. Status hold harus disimpan di database agar tetap konsisten jika layanan antrean crash. Sertakan seed data dan endpoint /health.

**Prompt 2 – Dokumen**
> Susun dokumen spesifikasi arsitektur dan Disaster Recovery Plan awal (aset kritis, skenario bencana, target RTO/RPO, strategi backup, prosedur recovery, query validasi) untuk studi kasus ticketing, dengan DR Test: crash Redis atau Database saat booking berjalan lalu pastikan kursi hold tetap konsisten.

*Catatan: tim wajib memahami kode dan dokumen ini sebelum dikumpulkan.*
